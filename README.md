# Mapeia Verde 🌳

Projeto de mapeamento e monitoramento de árvores urbanas no Rio de Janeiro e região metropolitana, com foco na organização de dados para apoiar a arborização urbana e a redução do calor.

## Objetivo

Desenvolver um banco de dados para gerenciar informações sobre árvores, levantamentos, vistorias, monitoramentos e relatórios técnicos.

## Tecnologias

- MySQL
- MySQL Workbench
- SQL
- Python para geração de dados de teste
- Git

## Funcionalidades

- Cadastro de clientes, contratos e projetos.
- Registro e localização de árvores.
- Registro de levantamentos e vistorias.
- Monitoramento das condições das árvores.
- Organização de relatórios técnicos.

## Instalação

1. Instale o [MySQL Server](https://dev.mysql.com/downloads/mysql/).
2. Instale o [MySQL Workbench](https://dev.mysql.com/downloads/workbench/).
3. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/mapeia-verde.git
   ```

4. Acesse a pasta do projeto:

   ```bash
   cd mapeia-verde
   ```

5. Abra o MySQL Workbench e conecte-se ao servidor MySQL.

## Execução

1. Abra o script SQL de criação do banco de dados no MySQL Workbench.
2. Execute o script para criar o banco e suas tabelas.
3. Execute os scripts de inserção para adicionar os dados de teste, caso disponíveis.
4. Execute os scripts de consultas para visualizar e analisar os dados.

Caso utilize scripts Python para gerar dados, instale o Python 3 e execute o script correspondente:

```bash
python3 nome_do_script.py
```

## Propósito

Utilizar dados confiáveis para apoiar o planejamento urbano e contribuir para cidades mais verdes, frescas e sustentáveis.
